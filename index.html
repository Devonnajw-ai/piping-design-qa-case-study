TEST GUIDE / NO AUTOMATIC PASS CLAIMS

Run your portfolio scenarios

TC-01 · Create a route

Start at A → Select B → Confirm route. Inspect both connection indicators and the model. Both endpoints should be connected.

TC-02 & TC-03 · Validate diameter

Select pipe route. Save 100 mm. Then try blank, 0, −25 (type -25), and abc separately. Each invalid value should show an error, and the committed diameter should stay 100 mm.

TC-04 · Edit without disconnecting

Save design. Select pipe route → Enter edit mode. Move the middle segment slider → Save edit. With bug simulation off, A and B should remain connected. With it on, B should disconnect.

TC-05 · Save and reopen

Use a connected, edited route at 100 mm. Save design → Close design → Reopen saved. Compare the geometry, offset, diameter, and both endpoints.

TC-06 · Cancel an edit

Start with a saved, connected route at 100 mm. Enter edit mode, move the slider, type 150 in the diameter field, then Cancel edit. Original geometry, 100 mm diameter, and both connections should be restored.
